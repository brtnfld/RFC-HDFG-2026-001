\revision{v1}{March 6, 2026}{Initial draft released for internal review.}
\revision{v2}{May 1, 2026}{Renamed to \texttt{H5Pappend\_filter}; \texttt{H5Z\_params\_t} made internal with convenience macros for callers. Dropped \texttt{name} field and Filter Name Registry in favour of \texttt{filter\_title} in \texttt{cd\_values}. Deferred on-disk format change. Added single-quoted string grammar production. Added Fortran, Java, and h5py binding designs. Documented \texttt{H5Pmodify\_filter} gap; addressed legacy plugin \texttt{cd\_nelmts} hazard and VOL thin-client limitation.}
\revision{v3}{May 12, 2026}{Added TOML VFD/VOL profile and use-case coverage (UC-1--UC-8) as non-normative forward-looking context; VFD/VOL API changes are out of scope. Community review: \texttt{true}/\texttt{false} are the only valid boolean literals; empty quoted strings (\texttt{key=""}) are valid. Clarified \texttt{H5Z\_CLASS\_T\_VERS\_MAX} versioning. Corrected SZIP \texttt{set\_config} (validates directly, does not delegate to \texttt{H5Pset\_szip}) and Fortran helper code (field-by-field struct construction).}
\revision{v4}{July 13, 2026}{In-file blob configuration storage was briefly folded into this RFC as a single feature, then split back out into its own follow-on RFC, RFC-HDFG-2026-003.}
\revision{v5}{July 15, 2026}{Adopted an on-disk format change: parameter string stored verbatim in pipeline v3.}
\revision{v6}{August 18, 2026}{Made pipeline message version~3 extensible: each filter entry now ends in a list of typed, length-delimited extension blocks with an explicit critical bit, replacing the fixed \texttt{config\_length}/\texttt{config} field pair.  The configuration string and a new canonical-name block for built-in filters are the first two block types; RFC-HDFG-2026-003's blob locator is reserved as a third.  Follow-on per-entry features now add block types rather than a version~4.}
\revision{v7}{August 18, 2026}{Added \texttt{H5Pmodify\_filter\_by\_idx}, an index-addressed edit API accepting the same \texttt{H5Z\_params\_t} as \texttt{H5Pappend\_filter}.  Closes the gap where \texttt{H5Pmodify\_filter} silently downgraded an entry from a stored configuration string to \texttt{get\_config} reconstruction, with remove-and-re-append the only alternative at the cost of pipeline order.  \texttt{H5Pmodify\_filter} is unchanged and undeprecated.}
\revision{v8}{August 18, 2026}{Pinned the version-3 libver gate to \texttt{H5F\_LIBVER\_V300} (the \texttt{V200} row stays at version~2), replacing the two-case release-timing hedge.  Corrected \texttt{H5Zconfig\_get\_bool} to take \texttt{bool~*}, the info accessor name to \texttt{H5Zget\_filter\_class\_info}, the version setter to \texttt{H5O\_pline\_set\_version}, and stale references to a singular \texttt{H5Zconfig\_get\_param} helper --- all verified against the implementation.}
